# ShopWatch-Lite

Groupe : Groupe 2

Mini-plateforme de supervision d'une boutique en ligne : trois agents
(Extraction, Analyse, Notification) qui echangent via un contrat commun
(src/contrat.py).

## Equipe

| Etudiant | Role | Fichiers |
| --- | --- | --- |
| A | Agent Extraction | `src/extraction.py`, `tests/test_extraction.py` |
| B | Agent Analyse | `src/analyse.py`, `tests/test_analyse.py` |
| C | Agent Notification | `src/notification.py`, `tests/test_notification.py` |
